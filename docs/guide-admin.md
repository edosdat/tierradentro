# Guide de l'administration · Tierradentro

**Adresse : https://tierradentro-eight.vercel.app/studio** (connexion avec ton compte Google).
Tout ce que tu publies apparaît sur le site **en quelques secondes**. Rien n'est en ligne tant que tu n'as pas touché **Publier**.

## Ajouter une date de concert
1. **Dates de concert** → **À venir** → bouton **+** (en haut).
2. Remplis : **Date**, **Heure** (facultatif, ex. `20:30`), **Projet**, **Salle**, **Ville**, **Département ou pays** (ex. `31`, ou `Maroc`).
3. **Lien billetterie** : colle l'adresse de la page de vente (elle doit commencer par `https://`).
4. **Statut** : *Confirmé* (par défaut), *Complet* ou *Annulé* — la date reste affichée, barrée si annulée.
5. **Publier**.

Astuce tournée : ouvre une date existante → menu **⋯** en haut à droite → **Dupliquer**, puis change la date et la salle.
Une date passée rejoint toute seule les **archives** le lendemain.

## Ajouter une vidéo à un projet
1. **Projets** → le projet → onglet **Photos et vidéos** → **Vidéos** → **Ajouter**.
2. Sur YouTube : **Partager** → **Copier** ; colle l'adresse, puis un **titre** et une **légende** (ex. « Teaser 2026 »).
3. La miniature s'affiche si l'adresse est bonne. **Publier**.

## Mettre à jour une fiche technique (ou tout document pro)
1. **Projets** → le projet → onglet **Espace pro** → **Documents à télécharger**.
2. Ouvre la ligne *Fiche technique* → **Fichier PDF** → remplace le fichier.
3. Change la **Date de mise à jour** (elle s'affiche : « mis à jour le … »). **Publier**.

## Ajouter une photo
Glisse la photo dans le champ, puis remplis **obligatoirement** :
- **Description** (ce que montre la photo, pour les personnes qui ne la voient pas) ;
- **Crédit photo** (ex. « © Marie Dupont »).
Le point rouge disparaît une seconde après la saisie. Le **bouton recadrage** permet de choisir le centre de l'image.

## Le reste, en bref
| Rubrique | Ce qu'on y trouve |
|---|---|
| Projets | présentation, distribution, photos, vidéos, discographie, documents pro |
| Personnes | musiciens et artistes, réutilisables d'un projet à l'autre |
| Presse | articles (les brouillons repris du site du Tafi attendent le nom du média) |
| Actualités | nouvelles du site |
| Partenaires | logos (le bandeau apparaît dès le premier logo publié) |
| Pages | mentions légales, confidentialité, crédits |
| L'association | mission, équipe, SIRET, licence, rapports d'activité |
| Réglages du site | accroche de l'accueil, contacts, vidéo à la une, **vidéo de fond**, réseaux sociaux |

**Traductions** : sous chaque texte, le volet **Traductions (facultatif)** contient l'anglais et l'espagnol.
Laissé vide, le site affiche le français.

**Se tromper n'est pas grave** : chaque document garde son historique (icône horloge en haut à droite) et se restaure en un clic.
