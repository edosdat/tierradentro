# Captures de référence

Captures du site du Cuarteto Tafi (cuartetotafi.com), fournies dans le kit du projet :
le colibri aquarelle, les pages Concerts, Discographie, Vidéos, Presse et Espace Pro.

Elles servent de référence visuelle : posture du colibri, salar sable sous ciel bleu,
jacaranda isolé, petits colibris en silhouette. Le site Tierradentro s'en inspire sans les copier.
